CLI reference

Every command, and every flag on run.

agentmesh --help
agentmesh --version

Commands

CommandWhat it does
runResolve needs, select or synthesize agents, execute the graph, report tokens and cost
list-projectsList available spec-pack projects
list-agentsList a project's agents, capabilities, and enabled state
validate-specLoad and validate every YAML spec in a project
init-projectDraft a new starter pack from a description, confirm, then write it
configure-modelsPrompt for API keys and defaults; merges into .env
check-modelsVerify providers resolve; --live sends one real request each
list-modelsShow routing keys, model ids, availability, and per-token cost
help-functionsPrint the command catalog with examples

agentmesh run

agentmesh run --project data_ops "Review this SQL query for quality risks"
FlagDefaultPurpose
--project, -prequiredWhich spec pack to run
--providerspec routingForce one provider for every agent
--modelspec routingForce one routing key or model id
--synthesize / --no-synthesizeonBuild agents for uncovered capabilities
--save-agentsoffPersist synthesized agents to the project
--overwrite-storedoffAllow --save-agents to replace existing specs
--max-attempts3Attempts per model call; 1 disables retries
--max-costnoneStop once estimated spend reaches this many USD
--max-workers4Agents run concurrently within a level
--log-levelWARNINGLogger threshold
--json-logsoffOne JSON object per model call
--spec-packs-dirspec_packsWhere to look for projects

Exit codes

CodeMeaning
0Run completed
1Spec load failure, or no usable provider
2Stopped on the budget ceiling you set

Common recipes

# fully offline, deterministic, no credentials
agentmesh run -p data_ops "..." --provider mock

# cheap model, strict ceiling, serial
agentmesh run -p data_ops "..." \
  --model anthropic/claude-haiku-4-5 --max-cost 0.10 --max-workers 1

# keep the agents this run invented
agentmesh run -p data_ops "Research the options" --save-agents

# machine-readable telemetry for a log pipeline
agentmesh run -p data_ops "..." --json-logs --log-level INFO

# validate every spec before committing
agentmesh validate-spec -p data_ops
