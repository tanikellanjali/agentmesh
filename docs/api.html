HTTP API

A FastAPI wrapper over the same run_project() the CLI calls. It adds no logic of its own, so the two entry points cannot diverge.

uvicorn agentmesh.api.server:app --reload
No authentication. No auth, no rate limiting, no request size caps. Run it on localhost or behind your own gateway.

Endpoints

MethodPathReturns
GET/healthStatus and version
GET/projectsAvailable spec packs
GET/projects/{id}/agentsEnabled agents and capabilities
POST/projects/{id}/runExecute the mesh

Status codes

CodeWhen
200Run completed; individual agents may still carry error
402Stopped on the max_cost ceiling you set
404Unknown project, or a spec failed to load
503No usable provider — the detail names every candidate

Using the runtime directly

from agentmesh.core.runtime import run_project

result = run_project(
    "data_ops", "Which supplier has the best margin?",
    principal=Principal(id="anjali", org="acme"),
    sources=registry,
    provider="anthropic",
    max_cost=0.50,
)
print(result.run.final_response, result.run.cost, result.recorder.data_cost)
