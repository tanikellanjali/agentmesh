Getting started

Install, run a mesh offline with no credentials, then connect a model and your data.

Install

git clone https://github.com/tanikellanjali/agentmesh
cd agentmesh
python -m venv .venv && source .venv/bin/activate
pip install -e ".[dev]"

Everything beyond the core is an optional extra, so a contributor with no API keys can still run the full test suite.

ExtraBrings
[anthropic] [openai] [providers]Model providers
[langgraph]Checkpointing, resume, human-in-the-loop
[mcp]Any MCP server's tools
[duckdb]CSV, Parquet, JSON with correct types
[sql]Postgres, MySQL, Oracle, Snowflake …
[all]All of the above

Run without credentials

agentmesh run --project data_ops "Review this SQL query for quality risks" --provider mock
┃ ID                 ┃ Capabilities                          ┃ Origin ┃ Level ┃
│ data_quality_agent │ data_quality_check, anomaly_detection │ spec   │   0   │
│ sql_analyzer_agent │ sql_analysis, query_review            │ spec   │   0   │
│ report_agent       │ report_generation, response_compos... │ spec   │   1   │

The mock provider still drives the real tool loop, so an offline run proves the plumbing rather than skipping it.

Add credentials

agentmesh configure-models      # prompts for keys, merges into .env
agentmesh check-models --live   # proves the keys actually work

.env is merged, not overwritten — adding OpenAI later will not wipe your Anthropic key. It is gitignored.

--live bills you. One real request per provider — a few tokens each, but real money on a real account.

Bind your data

from agentmesh.data.context import SourceRegistry
from agentmesh.data.duckdb_source import DuckDbSource

registry = SourceRegistry.empty()
registry.add_source(DuckDbSource("store_files", root="./data"))
registry.bind("transactions", "store_files", "purchases.csv")
from agentmesh.core.runtime import run_project

result = run_project("data_ops", "Which supplier has the best margin?",
                     sources=registry, max_cost=0.50)

Run against a real model

agentmesh run --project data_ops "..." --max-cost 0.50
agentmesh run --project data_ops "..." --provider anthropic --model anthropic/claude-sonnet-5
If nothing is usable, the run fails. AgentMesh names every candidate it tried and why each was rejected. It does not quietly degrade to a fake model, because fake output that looks real is worse than an error.
