AgentMesh is an open-source Python runtime for building internal agent meshes. Agents are YAML specs that call real tools over your own data. Capabilities nothing covers are synthesized at runtime. Every model call and every query is costed.

request → capabilities → matched or synthesized agents → dependency graph → tools & data → structured output
Get started View source $ pip install -e ".[dev,all]"

What it does

The runtime is the product. The CLI and the FastAPI wrapper are two doors into the same run_project() call, so they cannot drift apart.

🧬

Agents that don't exist yet

A capability nothing covers gets an agent written for it at runtime. Ephemeral by default, kept only when you ask, versioned when adapted.

Every call accounted for

Tokens, cost, retries and duration per model call; rows, bytes and cost per query. No default spending cap — AgentMesh will not pick your budget.

Built on the good parts of the ecosystem

AgentMesh decides which agents exist, why, and who may use them. It does not try to out-build the tools that already solve execution and connectivity.

ConcernHandled byWhy
Registry, synthesis, versioning, permissionsAgentMeshNobody else does this as a product primitive
Durable execution, checkpoints, interruptsLangGraphResumable state is a distributed-systems problem
Tools and SaaS connectorsMCPHundreds of servers, maintained by the vendors
Files: CSV, Parquet, JSONDuckDBCorrect type inference and pushdown
Databases: Postgres, Oracle, SnowflakeSQLAlchemyOne adapter, every dialect

Execution is a graph, not a list

An agent with the response_composition capability implicitly waits for everyone else and writes the final answer — so the response comes from the composer, not from whichever agent happened to finish last.

Sixty seconds to a running mesh

Offline, no credentials

git clone https://github.com/tanikellanjali/agentmesh
cd agentmesh
pip install -e ".[dev]"

agentmesh run --project data_ops \
  "Review this SQL query" --provider mock

Then plug in a real model

pip install -e ".[all]"

agentmesh configure-models    # your keys
agentmesh check-models --live # prove they work

agentmesh run --project data_ops \
  "Review this SQL query" --max-cost 0.50
No silent fallbacks. If no provider is usable the run fails, naming every attempt. AgentMesh will never hand you placeholder output dressed up as a real answer.
