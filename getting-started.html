Getting started

Install AgentMesh, run a mesh offline with no credentials, then point it at a real model.

Requirements

  • Python 3.11 or newer
  • An Anthropic or OpenAI API key — optional; the mock provider needs neither

Install

git clone https://github.com/tanikellanjali/agentmesh
cd agentmesh
python -m venv .venv && source .venv/bin/activate
pip install -e ".[dev]"

Provider SDKs are optional extras, so a contributor with no API keys can still run the full test suite.

pip install -e ".[anthropic]"   # Claude
pip install -e ".[openai]"      # OpenAI
pip install -e ".[providers]"   # both

Run without credentials

The mock provider is deterministic and never touches the network, so you can see the whole pipeline before deciding on a model:

agentmesh run --project data_ops "Review this SQL query for quality risks" --provider mock
┃ ID                 ┃ Capabilities                          ┃ Origin ┃ Level ┃
│ data_quality_agent │ data_quality_check, anomaly_detection │ spec   │   0   │
│ sql_analyzer_agent │ sql_analysis, query_review            │ spec   │   0   │
│ report_agent       │ report_generation, response_compos... │ spec   │   1   │

Add your credentials

agentmesh configure-models

This prompts for the keys you have and, optionally, a default provider and model. It writes .env, merging with what is already there — re-running it to add one provider will not wipe another's key. .env is gitignored.

agentmesh check-models --project data_ops          # do the providers resolve?
agentmesh check-models --project data_ops --live   # do the keys actually work?
--live bills you. It sends one real request per provider — a few tokens each, but real money on a real account.

Run against a real model

agentmesh run --project data_ops "Review this SQL query"

# force one model for the whole run
agentmesh run --project data_ops "..." \
  --provider anthropic --model anthropic/claude-sonnet-5

# stop at a ceiling you choose
agentmesh run --project data_ops "..." --max-cost 0.50
If nothing is usable, the run fails. AgentMesh names every candidate it tried and why each was rejected. It does not quietly degrade to a fake model, because fake output that looks real is worse than an error.

Start the HTTP API

uvicorn agentmesh.api.server:app --reload

curl -X POST http://127.0.0.1:8000/projects/data_ops/run \
  -H "Content-Type: application/json" \
  -d '{"message":"Review this SQL query.","provider":"mock"}'
The API has no authentication yet. Do not expose it publicly. See the API reference.
