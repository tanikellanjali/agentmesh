AgentMesh is an open-source Python runtime for building internal agent meshes. Agents are YAML specs, not classes. Capabilities nothing covers are synthesized at runtime. Every model call is retried, costed, and logged.

user request → required capabilities → matched or synthesized agents → dependency graph → structured output
Get started View source $ pip install -e ".[dev,providers]"

What it does

The runtime is the product. The CLI and the FastAPI wrapper are two doors into the same run_project() call, so they cannot drift apart.

🧬

Agents that don't exist yet

When a request needs a capability no registered agent covers, AgentMesh writes an agent for it and runs it. Ephemeral by default, saved only when you ask.

A real dependency graph

Agents declare depends_on and run in topological levels. Independent agents run concurrently. Cycles fail at build time, not mid-run.

Bring your own model

Claude and OpenAI adapters behind one provider interface, plus a deterministic mock for offline work. Your keys, your model, per-agent routing.

Retries that know better

Backoff with jitter on 5xx, connection errors, and rate limits. Auth failures and refusals fail immediately instead of burning attempts.

📊

Every call accounted for

Tokens, cost, attempts, duration, and outcome recorded per model call, not per agent. Human tables or one JSON object per call.

💸

Your budget, your call

There is no default spending cap. AgentMesh will not pick one for you. Set --max-cost when you want a ceiling.

Budgets →

Execution is a graph, not a list

Agents run in dependency levels. An agent with the response_composition capability implicitly waits for everyone else and writes the final answer, so the response comes from the composer rather than whichever agent happened to finish last.

Two independent analysts run concurrently in level 0; the composer reads both in level 1.

Sixty seconds to a running mesh

Install and run offline

git clone https://github.com/tanikellanjali/agentmesh
cd agentmesh
pip install -e ".[dev]"

agentmesh run --project data_ops \
  "Review this SQL query" --provider mock

No credentials required. The mock provider is deterministic.

Then plug in a real model

pip install -e ".[anthropic]"

agentmesh configure-models    # your keys
agentmesh check-models --live # prove they work

agentmesh run --project data_ops \
  "Review this SQL query" --max-cost 0.50

Keys are merged into .env, which is gitignored.

No silent fallbacks. If no provider is usable, the run fails with an explicit error naming every attempt. AgentMesh will never hand you placeholder output dressed up as a real answer.
