Models & credentials

You choose the provider and the model and supply the keys. AgentMesh routes each agent, and never substitutes a fake model when the real one is unavailable.

Providers

NameBackendRequires
anthropicClaude, official SDKANTHROPIC_API_KEY + [anthropic]
openaiOpenAI, official SDKOPENAI_API_KEY + [openai]
mockDeterministic, drives the real tool loopnothing
localAlias for mock until an Ollama adapter landsnothing

Both SDKs are lazily imported. A missing SDK or key gives a named error, not an ImportError halfway through a run.

Precedence

  1. --provider / --model on the command
  2. AGENTMESH_PROVIDER / AGENTMESH_MODEL in the environment
  3. The agent spec's models.default, then each models.fallback

Model routing

A stable routing key maps to a provider, the real model id, and per-token cost — so a vendor renaming a model is a one-line change, not a sweep through every spec.

models:
  anthropic/claude-opus-5:
    provider: anthropic
    model: claude-opus-5
    cost_per_1k_input_tokens: 0.005
    cost_per_1k_output_tokens: 0.025
    max_tokens: 4096
Verify the pricing. The numbers in the example pack are a starting point. Check them against each vendor's current price list before trusting a cost report.

Fallback chains actually degrade

An agent's models.fallback list is tried in order; a provider that cannot be constructed is skipped for the next candidate. If nothing works, the run stops and says what it tried:

No usable model for agent 'sql_analyzer_agent'
  (anthropic/claude-opus-5 -> anthropic: ANTHROPIC_API_KEY is not set.;
   openai/gpt-4.1-mini -> openai: OPENAI_API_KEY is not set.).
Run `agentmesh configure-models`, or use --provider mock to run offline.
The chain never ends at a mock. Degrading to fake output would make a broken configuration look like a working one. Use --provider mock when you want that, explicitly.

Writing a provider

class MyProvider(SingleShotMixin):
    name = "my-provider"

    def converse(self, *, system, messages, tools=None, model, max_tokens=4096, effort=None):
        return Turn(text=..., provider=self.name, model=model,
                    tool_calls=[...], usage=Usage(...))

register_provider("my-provider", MyProvider)

Raise ProviderTransientError for anything worth retrying and ProviderAuthError for anything that is not.
